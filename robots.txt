# Updated: 2026-09-10

# Nothing is Disallowed on purpose. Pages that should stay out of the index
# (vault.html, galley/*, design-system/*) carry a noindex instead — either a
# meta robots tag or the X-Robots-Tag header set in _headers. A crawler has to
# be able to FETCH a page to see a noindex, so Disallow would defeat it and
# leave those URLs stuck in "blocked by robots.txt" limbo.
#
# The AI crawlers below are named explicitly rather than left to the wildcard.
# Two reasons: some agents only read their own named block, and two of them
# (Google-Extended, Applebot-Extended) are pure opt-in/opt-out switches for AI
# grounding and training that a wildcard rule does not speak to. Naming them is
# an explicit yes. This site wants to be read, quoted and cited by assistants.
#
# Machine-readable summaries for language models:
#   https://dharun.dev/llms.txt       — index, one screen
#   https://dharun.dev/llms-full.txt  — the whole profile in one fetch
